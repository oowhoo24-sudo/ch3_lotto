# ch3_lotto
# 🎲 Streamlit 로또 번호 생성기

간단하고 직관적인 웹 기반 로또 번호 생성 프로그램입니다.  
Streamlit을 기반으로 제작되었으며, 실제 동행복권의 번호 대역별 공 색상을 반영했습니다.

---

## 📌 주요 기능
- **랜덤 번호 추출**: 1~45 사이의 중복 없는 6개 번호를 무작위로 추출
- **최대 5세트 누적**: 버튼을 누를 때마다 한 세트씩 추가되며, 최대 5세트까지 화면에 유지
- **공식 로또 색상 적용**:
  - 1 ~ 10: 노란색
  - 11 ~ 20: 파란색
  - 21 ~ 30: 빨간색
  - 31 ~ 40: 회색
  - 41 ~ 45: 녹색
- **가로 정렬 UI**: 번호 6개가 한 줄로 깔끔하게 정렬
- **초기화 버튼**: 생성된 세트를 한 번에 비우고 새로 시작 가능
